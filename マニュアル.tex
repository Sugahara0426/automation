\section{Piezo調整}

\subsection{スイッチをVNA側・使用するモードに切り替える}

\begin{command}

% python Switchcontrol.py VNA TM110

\end{command}

\begin{itemize}

\item TM210の場合はTM210を指定する。

\end{itemize}

\subsection{ANC350をLinux PCに接続する}

ANC350をUSBでLinux PCに直接接続する。
Windows PCでの事前接続・初期化と、USBの差し替えは不要。

\subsection{Linux PCで受信プログラムを起動する：frequency\_controller.py}

\begin{command}

% python frequency_controller.py

\end{command}

\begin{itemize}

\item Waiting for frequency command...と表示されたら、別タブから指示を送る。

\item このターミナルは起動したままにする。

\item この受信側のターミナルに、現在の周波数・目標との差・移動step数・最終結果が表示される。

\item 調整終了後は、次の指示を待ち受ける。

\end{itemize}

\subsection{別タブでPythonを起動し、送信側を準備する}

\subsection{python起動後}

\begin{command}

>>> from frequency_command import FrequencyCommandProducer

>>> producer = FrequencyCommandProducer()

>>> producer.send_target("TM110", 1897400)

\end{command}

\begin{itemize}

\item 引数1：TM110 or TM210

\item 引数2：目標周波数 ［kHz］

\end{itemize}

\subsection{送信側の通信を閉じる}

\begin{command}

>>> producer.close()

\end{command}

\subsection{調整条件と保存ファイル}

\begin{itemize}
\item 目標との差が$\pm10$ kHz以内で完了。最大反復回数は10回。
\item 正負のslope測定後、フィードバック移動前のグラフを \texttt{tuning00} として保存する。
\item 以降は \texttt{tuning01}、\texttt{tuning02}と続く。
\item 完了したPNGは \texttt{tuning03\_final.png} などとなり、図にも(Final)を表示する。
\end{itemize}

各回の移動前にVNAを10回測定し、平均CSV・PNGをcontrollerと同じ場所の
\texttt{data/YYYYMMDD/}、生データCSVをその中の \texttt{raw\_data/} に保存する。
CSVにはfinalを付けない。ピエゾの位置・駆動設定は自動保存しない。
controllerは駆動電圧・周波数を自動設定しないため、変更する場合は起動前に設定する。

\section{Piezoの個別操作}

\subsection{スイッチをVNA側・使用するモードに切り替える}

\begin{command}

% python Switchcontrol.py VNA TM110

\end{command}

\begin{itemize}

\item TM210の場合はTM210を指定する。

\end{itemize}

\subsection{ANC350をLinux PCに接続する}

ANC350をUSBでLinux PCに直接接続する。
Windows PCでの事前接続・初期化と、USBの差し替えは不要。

\subsection{Linux PCでPythonを起動し、ANC350に接続する}

\begin{command}

>>> import piezo_tools

>>> atc = piezo_tools.connect_piezo()

\end{command}

\begin{itemize}

\item frequency\_controller.pyとの同時接続はできない

\end{itemize}

TM110：axis1、TM210：axis2


\subsection{現在位置・駆動設定を確認する}

\begin{command}
>>> piezo_tools.get_position(atc)
>>> piezo_tools.get_drive_settings(atc)
\end{command}

全軸の位置［m］、ステップ電圧・周波数などを表示する。

\subsection{ステップ電圧・周波数を設定する}

\begin{command}
>>> piezo_tools.set_step_voltage(atc, 1, 30.0)
>>> piezo_tools.set_step_frequency(atc, 1, 1500)
\end{command}

第2引数は軸番号。電圧［V］と周波数［Hz］を設定する。
設定変更後はslopeを測り直す（自動調整の開始時に測定される）。

\subsection{指定したstep数だけ移動する}

\begin{command}

>>> piezo_tools.move_steps(atc, axis, 10, delay=0.01, settle=1.0)

\end{command}

\begin{itemize}

\item atcの次の引数：軸番号

\item その次の引数：移動step数。負方向なら-10などを指定する。

\item delay：step間の待ち時間、settle：移動後の待ち時間［秒］

\end{itemize}

\subsection{初期位置へ戻す}

\begin{command}
>>> ok = piezo_tools.reset_position(atc, axes=(1,))
\end{command}

axes=(1,)はTM110のみ。axesを省略するとTM110・TM210の両軸を戻す。
初期位置はTM110が7.090 mm、TM210が4.185 mm。
許容誤差は50 $\mu$m、待機上限は30秒。
現在位置から0.5 mmを超えて離れた目標への移動は拒否される。

\subsection{位置・駆動設定を保存する}

\begin{command}
>>> means = piezo_tools.measure_and_save(atc, suffix_arg="check")
\end{command}

実行フォルダの \texttt{data/YYYYMMDD/RunNNN/} に平均位置・駆動設定と生データのCSVを保存する。

\subsection{操作終了後、通信を閉じる}

\begin{command}

>>> piezo_tools.disconnect_piezo(atc)

\end{command}

\section{パワーのfeedback}

\subsection{パワー測定値の送信を開始する：RaS\_NRP2\_Operator.py}

\begin{command}

% python RaS_NRP2_Operator.py

\end{command}

\begin{itemize}

\item このターミナルは起動したままにする。

\end{itemize}

\subsection{スイッチをAMP側・使用するモードに切り替える}

\begin{command}

% python Switchcontrol.py AMP TM110

\end{command}

\begin{itemize}

\item TM210の場合はTM210を指定する。

\end{itemize}

\subsection{別タブでPythonを起動し、フィードバックを準備する}

\subsection{python起動後}

\begin{command}

>>> from power_feedback import PowerFeedbackController

>>> feedback = PowerFeedbackController()

>>> feedback.start(frequency_ghz=1.8974, target_power_w=7e-6, initial_amp_power_dbm=-25.0)

\end{command}

\begin{itemize}

\item frequency\_ghz：AMPの周波数［GHz］。必須。省略できない。

\item target\_power\_w：NRP2 CH2で測定する目標パワー［W］。省略時は現在の設定値を使う（初期値7 $\mu$W）。

\item initial\_amp\_power\_dbm：開始時のAMP出力［dBm］。省略時は既定値$-30$ dBm。ただし現在の下限制限により実際は$-25$ dBm。

\item 周波数設定 → 初期AMP出力設定 → AMP出力ON → フィードバック開始まで行う。

\end{itemize}

デフォルト値とAMP出力の上限・下限は、power\_feedback.pyの冒頭にまとめて記載している。

周波数だけを指定して開始する場合：

\begin{command}
>>> feedback.start(frequency_ghz=1.8974)
\end{command}

\subsection{設定の変更}

変更後の設定は、次の制御計算から使われる


目標パワーを変更する


\begin{command}

>>> feedback.set_target_power(7e-6)

\end{command}

\begin{itemize}

\item 引数：目標パワー［W］

\end{itemize}

PIDの係数を変更する


\begin{command}

>>> feedback.set_pid(kp=1.0, ki=0.0, kd=0.0)

\end{command}

制御の更新間隔を変更する


\begin{command}

>>> feedback.set_interval(1.0)

\end{command}

\begin{itemize}

\item 引数：更新ごとの待ち時間［秒］

\end{itemize}

\subsection{現在の状態を確認する}

\begin{command}

>>> feedback.get_status()

\end{command}

\begin{itemize}

\item AMP出力ON/OFF、フィードバック状態、周波数、AMP出力、目標値、最新の測定値などを表示する。

\end{itemize}

\subsection{フィードバックを停止し、SG出力をOFFにする}

\begin{command}

>>> feedback.stop()

\end{command}

\subsection{ログのパスを確認}

\end{command}

\section{1port運用}

TM110・TM210の両方を、TM110側の入力ポートで測定する。

\subsection{スイッチを切り替える}

\begin{command}
% python Switchcontrol_1port.py VNA TM110
\end{command}

TM110／TM210のどちらを指定しても、物理入力はTM110側に固定される。

\subsection{Piezo調整の受信側を起動する}

\begin{command}
% python frequency_controller_1port.py
\end{command}

送信方法・周波数の単位・調整条件は通常版と同じ。
保存するCSV・PNGの名前に1port\_input\_TM110が付き、図にも入力ポートを表示する。
