使い方

スイッチの切り替え：Switchcontrol.py


◯特性評価/実験、TM110/TM210を切り替える

% python Switchcontrol.py AMP TM110
・引数1 VNA or AMP
・引数2 TM110 or TM210

◯スイッチ用電源のCH2・CH3・CH4の出力を全てOFFにする

% python Switchcontrol.py OFF

◯python起動後
>>>import Switchcontrol
>>>Switchcontrol.set_switch("VNA", "TM110")
・引数1 VNA or AMP
・引数2 TM110 or TM210
または
 >>>Switchcontrol.all_off()






































VNAの設定・測定・CSV保存：test_main.py


◯VNA接続 → 測定条件の設定 → 全4chを各10回測定 → CSV保存をまとめて行う


% python test_main.py
・保存ファイル名の末尾を指定する % python test_main.py TM110_check
引数：ファイル名の末尾に付ける文字列






VNAの個別操作：vna_tools.py


①Python起動後、VNAと接続
>>> import pyvisa
>>> import vna_tools
>>> rm = pyvisa.ResourceManager('@py')
>>> znb = vna_tools.get_vna_resource(rm, 'TCPIP0::192.168.12.4::inst0::INSTR')

◯測定条件・トレース・画面・マーカーを設定する
>>> vna_tools.setup_vna(znb)
・TM110/TM210それぞれのWide/Narrowを全4chに設定する。

◯全4chを各10回測定し、CSVを保存する
>>> csv_path = vna_tools.measure_and_save(znb)

◯現在のNarrow S11から、最小振幅の周波数を取得する
>>> f0, amp_min = vna_tools.find_min_freq(znb, 2, "Trc4")
・TM110：2, "Trc4"
・TM210：4, "Trc9"

◯操作終了後、通信を閉じる
>>> znb.close()
>>> rm.close()











Piezo調整

①スイッチをVNA側・使用するモードに切り替える


% python Switchcontrol.py VNA TM110


・TM210の場合はTM210を指定する。


②ANC350を初期化する：piezo_move.py
・ ANC350をUSBでWindows PCに接続する。
・ Windows PCで piezo_move.py を実行し、初期化する。
・ USBをWindows PCからLinux PCへ差し替える。


③Linux PCで受信プログラムを起動する：frequency_controller.py

% python frequency_controller.py


・Waiting for frequency command...と表示されたら、別タブから指示を送る。
・このターミナルは起動したままにする。
・この受信側のターミナルに、現在の周波数・目標との差・移動step数・最終結果が表示される。
・調整終了後は、次の指示を待ち受ける。

④別タブでPythonを起動し、送信側を準備する

◯python起動後
>>> from frequency_command import FrequencyCommandProducer
>>> producer = FrequencyCommandProducer()
>>> producer.send_target("TM110", 1897400)
・引数1：TM110 or TM210
・引数2：目標周波数 ［kHz］

◯送信側の通信を閉じる
>>> producer.close()





















パワーのfeedback

①パワー測定値の送信を開始する：RaS_NRP2_Operator.py

% python RaS_NRP2_Operator.py

・このターミナルは起動したままにする。

②スイッチをAMP側・使用するモードに切り替える


% python Switchcontrol.py AMP TM110


・TM210の場合はTM210を指定する。



③別タブでPythonを起動し、フィードバックを準備する

◯python起動後
>>> from power_feedback import PowerFeedbackController
>>> feedback = PowerFeedbackController()
>>> feedback.start(frequency_ghz=1.8974, target_power_w=7e-6, initial_amp_power_dbm=-25.0)


・frequency_ghz：SGの周波数［GHz］
・target_power_w：NRP2 CH2で測定する目標パワー［W］
・initial_amp_power_dbm：開始時のSG出力［dBm］
・周波数設定 → 初期SG出力設定 → SG出力ON → フィードバック開始まで行う。

◯設定の変更
変更後の設定は、次の制御計算から使われる

目標パワーを変更する
>>> feedback.set_target_power(7e-6)
・引数：目標パワー［W］


PIDの係数を変更する
>>> feedback.set_pid(kp=1.0, ki=0.0, kd=0.0)

制御の更新間隔を変更する
>>> feedback.set_interval(1.0)
・引数：更新ごとの待ち時間［秒］





◯現在の状態を確認する
>>> feedback.get_status()
・SG出力ON/OFF、フィードバック状態、周波数、SG出力、目標値、最新の測定値などを表示する。


◯フィードバックを停止し、SG出力をOFFにする
>>> feedback.stop()

◯ログのパスを確認
>>> print(feedback.log_path)

◯測定ログのリアルタイム確認
別のタブで
% tail -f ログのパス



1port運用
TM110・TM210の両方を、TM110側の入力ポートで測定する。

◯スイッチ操作はSwitchcontrol_1port.pyを使用する
・TM110／TM210のどちらを指定しても、物理入力はTM110側に固定される。

◯Piezo調整の受信側はfrequency_controller_1port.pyを使用する
・周波数調整の処理・piezo軸・周波数範囲は従来版と同じ
・保存するCSV・PNGの名前に1port_input_TM110を追加。
・保存する図に、入力がTM110側であることを表示。
